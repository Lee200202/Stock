## 3. 個股面板改版

### 3.1 現況（嘉澤 3533 實測）
- K 線工具列一共 **16 個膠囊**，分三行，而且長得都一樣：
  - 週期：日、週、月、60分；
  - 均線：MA5、MA10、MA20（黑底）、自訂輸入框、新增均線；
  - 布林通道（被擠到第二行）；
  - 區間：1月、3月、6月、1年、全部；
  - 副圖：MACD、KD。
- 讀者看不出哪幾顆是「一組只能選一個」（週期、區間），哪幾顆是「可以多選的開關」（均線、布林、副圖），哪一顆是「動作」（新增均線）。
- 游標放在 K 線上捲動滑鼠時，圖會被拖動，頁面卻不會往下捲（實測嘉澤：往上捲一下，圖就把 9/24 那根移出畫面）。
- 十字線日期顯示「23 9月 '26」，不是站上其他地方用的 `2026/09/23`。

### 3.2 週期改成一顆完整的膠囊分段控制（你要的「完整橢圓形」）

```
┌────────────────────────────────────────┐
│ ▐██ 日 ██▌   週      月      60分       │   ← 一個膠囊外框，裡面四段等寬
└────────────────────────────────────────┘
```

規格：
- 外框：`display:inline-grid; grid-template-columns:repeat(4,1fr); border-radius:999px; padding:4px; background:var(--panel-2); border:1px solid var(--rule);`
- 每一段：`border-radius:999px; min-width:64px; height:36px`（觸控裝置 44px）；文字 14px × `--rd-fs`；沒選中是 `--muted` 文字、透明底。
- 選中那一段：白底（深色模式用 `--panel`）、`--ink` 文字、`box-shadow:0 1px 2px rgba(0,0,0,.12)`；切換時底色塊用 `transform` 滑到新位置（180ms，`prefers-reduced-motion` 時直接跳）。
- 語意：`role="radiogroup"`、每段 `role="radio"`、`aria-checked`；左右方向鍵切換。
- 放在工具列第一行最左邊，**全站只有這一個膠囊分段**在個股面板上。
- 手機：四段仍在同一個膠囊內，寬度 100%。
- 市場詳情面板（MarketDetail）的「近 6 小時／60 分 K／日 K／週 K／月 K」用同一個元件，兩邊外觀一致。

### 3.3 其他控制改成不是膠囊（避免太多橢圓形）

| 控制 | 性質 | 新樣式 |
|---|---|---|
| 區間（1月、3月、6月、1年、全部） | 單選，但重要性低於週期 | **文字分段**：純文字，選中那個下面一條 2px 主色底線；放在圖表右上角同一行，不佔新的一行 |
| 均線 MA5／MA10／MA20＋自訂 | 多選開關，每條線有顏色 | **圖例標籤**：圓角 6px 的小方塊，左邊 12×3px 的線條色塊（與圖上該線同色），關閉時灰字＋色塊變空心；直接放在 K 線圖左上角當圖例，點圖例就開關 |
| 新增均線 | 動作 | 圖例最後一個「＋」小方塊，點了在原位展開數字輸入框＋「加入」按鈕（圓角 8px），不用膠囊 |
| 布林通道 | 多選開關 | 與均線同一組圖例標籤 |
| 副圖 MACD／KD | 多選開關 | 放在各自副圖的標題列右邊：一個小開關（toggle switch）或「隱藏」文字按鈕，不放在主工具列 |

改完後主工具列只剩一行：「週期膠囊」＋右側「區間文字分段」；均線與布林變成圖例；副圖開關在副圖標題。

### 3.4 捲動與日期
- 滑鼠滾輪：**預設讓頁面捲動**，按住 Ctrl（Mac 為 ⌘）＋滾輪才縮放 K 線；第一次在圖上捲動時在圖中央淡淡顯示「按住 Ctrl 再捲動可縮放」1.5 秒。觸控維持雙指縮放、單指拖曳。⚠ 需同步修改 AGENTS.md v42（目前規定 mouseWheel 一律開啟）。
- 十字線與時間軸日期：lightweight-charts 設 `localization.timeFormatter` 回 `YYYY/MM/DD`（60 分 K 為 `MM/DD HH:mm`），與站上其他日期一致。

### 3.5 K 線圖上直接標出進出場（讓取價一眼看懂）
lightweight-charts 4.1.3 支援 `series.setMarkers()` 與 `series.createPriceLine()`，不需要新套件：
- 在 K 線上標記：
  - 第一次提到那天：小三角形（灰色）＋文字「提到」；
  - 實際成交那天：實心三角形（紅，買進）或倒三角形（綠，賣出）＋文字「進場 1565」；
  - 出場那天：倒三角形＋「出場 ＿」。
- 水平價格線：
  - 進場價：實線，標籤「進場 1565」；
  - 明講價：虛線，標籤「明講 1580」。
- 只在日 K 顯示這些標記；週、月、60 分 K 不畫，避免對不到根。

## 4. 取價區間圖改版

### 4.1 現在為什麼不直覺（嘉澤實測）
```
取價區間
進場  8/19   ─●──○═══════────────────────   1565.00  當日最低／明講 1580 買進
目前         ─━━━━━━━━ +7.99% ━━━━━━━━━━●─   1690.00  目前價
圖例：● 採用價　○ 張震明講　═ 當日最低～最高
```
1. **沒有價格刻度**：兩條軌道共用一把看不見的尺，點的位置對不到數字，讀者只能看右邊的數字。
2. **兩列是不同的東西卻排成同一種樣子**：第一列是「某一天的區間＋三種記號」，第二列是「一段漲跌」。
3. **要靠圖例解碼**：實心點、空心圈、淡色帶三種符號，第一次看的人要先讀圖例。
4. **日期互相矛盾**：面板上方寫「首次提到買入 2026/08/12」，持股追蹤卡片寫「8/12 進場 1565.00」，取價區間卻寫「進場 8/19」。原因：卡片（`tradeAxis`）用回合開始日 `roundStart`（第一次提到，8/12），取價區間（`pxRangeHtml`）用實際成交日 `r.entryDate`（8/19，當日最低 1565）。**持股卡片把 8/19 的價格配上 8/12 的日期**，這是資料呈現錯誤，要先修。
5. 「首次提到買入」單獨一張小卡，和取價區間是同一件事卻分成兩塊。

### 4.2 建議做法 A（推薦）：「進場以來走勢」小圖
把取價區間換成一張時間軸小圖，讀者直接看到「從哪一天、什麼價位開始，到現在怎麼走」：

```
進場以來走勢                                    +7.99%
1750 ┤                                   ╭╮
1700 ┤                                  ╭╯╰● 1690 目前
1650 ┤        ╭─╮                      ╭╯
1600 ┤ ─ ─ ─ ─│─│─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─│─ ─  明講 1580（虛線）
1565 ┤━━━━━━━▲━━━━━━━━━━━━━━━━━━━━━━━━━━━  進場 1565（實線）
1500 ┤         ╰─╮   ╭─╯
     └──┬──────┬───────┬───────┬───────┬──
       8/12   8/19    9/1     9/15    9/24
       提到   成交
```
規格：
- 資料：面板已經取回的日 K（`apiGetCandlesBundle` 的 day），從「第一次提到」前 3 個交易日畫到今天，**不另打 API**。
- 線：每日收盤折線；進場價以上的區域淡紅、以下淡綠（台股慣例，與 v54 小卡同一套逐段著色）。
- 兩條水平線：進場價（實線）、明講價（虛線，沒有就不畫）；線的右端直接寫文字標籤，**不需要圖例**。
- 兩個日期記號：「提到」（空心圈、灰）與「成交」（實心三角、紅）。兩者同一天時只畫成交。
- 右上角大字報酬，下方一行小字寫規則：「進場取 8/19 當日最低 1565；明講 1580 以下買進。」
- 已出場的回合：線畫到出場日，出場日畫倒三角與「出場（當日最高）＿」。
- 多回合：只畫目前回合；上方一行，例如鴻海「第 3 回合，累積 +22.77%」，點開才列前面各回合。
- 高度：桌面 180px、手機 150px；滑鼠停在線上顯示「9/15 收盤 1520，−2.9%」。
- 沒有日 K（「日 K 未涵蓋」）時退回做法 B。

### 4.3 建議做法 B（精簡）：一把有刻度的價格尺
沒有日 K、或要放在很窄的地方時使用：

```
          明講 1580
             ▽
 1550 ─────●───┼════════╪══════════════════●───── 1700
         進場 1565    8/19 當日區間      目前 1690
                      1565～＿（當日最高）   +7.99%
```
- 只有**一條**水平價格尺，兩端與中間寫刻度（取整：1550、1600、1650、1700）。
- 當日區間是尺上的淡色帶，進場與目前是兩個有文字標籤的點，明講價是尺上方的小倒三角＋文字。
- 進場點到目前點之間畫一段有顏色的線（紅漲綠跌），報酬寫在線的正上方。
- 所有記號旁邊直接寫文字，不需要圖例。

### 4.4 面板上方「持有期間」區塊整併
- 「首次提到買入」這張小卡拿掉，改成做法 A 小圖上方的一行：「8/12 第一次提到 → 8/19 成交 → 持有 N 個交易日」。
- 持股追蹤卡片的交易軸左端也要改：「8/19 進場 1565（當日最低）」，底下灰字「8/12 提到，明講 1580 以下買進」。這樣卡片、面板、取價圖三處日期一致。
- 測試：同一檔的卡片進場日、面板成交日、小圖成交記號三者相同；提到日與成交日不同時兩者都要出現。
