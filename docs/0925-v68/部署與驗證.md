## 二、取價規則與績效怎麼算

| | v61～v67（正式站現況） | v68 |
|---|---|---|
| 明講買入 | 成交日當日最低 | 成交日當日最低 |
| 首次明講會員持有 | 聲明日**收盤** | 聲明日（或之前最近交易日）**當日最低** |
| 明講賣出 | 出場日當日最高 | 出場日當日最高 |
| 轉觀望不碰 | 出場日（或之前）**收盤** | 出場日（或之前最近交易日）**當日最高** |
| 逾期 10 個交易日未再提及 | 最後提及日（或之前）**收盤** | 最後提及日（或之前最近交易日）**當日最高** |

- 張震明講的價位（明講 1580 以下買進、明講成本 2250）仍只作灰字附註；後台「現有持股」手動修正的成本仍優先。
- 持有聲明、轉觀望、逾期只取當天或之前的 K 棒，不借用未來 K 棒。
- 這是 9/24 定下的 v58 規則；v61 把持有聲明與非賣出出場改成收盤基準，這次依管理者確認撤回，並寫進 AGENTS.md，之後不得再改回收盤。

**績效計算流程**（沒改，列出來確認）：

1. **持股追蹤**（rebuildHoldingsTrackerJob）：依操作紀錄與會員持股切出每一檔的回合，用上表算進場價、出場價，寫進「持股追蹤」分頁與回合JSON。
2. **持股追蹤畫面**：持有中＝（最新成交價或最後一根收盤 − 進場價）÷ 進場價；已出場＝（出場價 − 進場價）÷ 進場價；多回合連乘成累積報酬。
3. **每日績效**（snapshotPerformanceJob）：當天所有持有中回合的未實現報酬取算術平均、正報酬比例、持有檔數，只寫交易日。
4. **歷史績效重算**（rebuildPerformanceHistoryJob）：用回合JSON 的進場價，逐日拿收盤價重算每一天持有中各檔的平均報酬；出場當天起那一檔不再列入。

所以**出場價只影響已出場那一回合的報酬**（持股追蹤「已出場」與累積報酬），不影響績效走勢；**進場價改變（持有聲明改取最低）會影響績效走勢**，部署後一定要重算歷史績效。
