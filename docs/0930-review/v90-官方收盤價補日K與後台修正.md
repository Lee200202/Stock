## 二、改了什麼

1. **官方收盤行情自動補日K**（Cachebuilder.gs）：收盤後 14:40 起，近五個交易日追蹤中的股票缺有效日K時，用證交所 MI_INDEX（上市）與櫃買 dailyQuotes（上櫃）補上。一天兩個請求涵蓋全部股票；只補缺的、不覆蓋既有資料；量用成交股數（股）與日K快取同單位；沒有成交的不補；官方還沒公布的日子留給下一棒。補到就從最早那一天重算持股追蹤與歷史績效（不重寫郵件、不重寄）。16:45 補日K做完後也先補一次再重算。系統狀態寫「官方日K補齊：09/29 N 檔、09/30 N 檔」。
2. **後台補日K卡片**：失敗過半改黃色，寫出成功／失敗／略過數，不再「做完」就綠色。
3. **現有持股儲存**：Worker 與 SiteBridge 參數上限改 8；只改成本或說明時只送 5 個參數（舊版橋接也收得下）；失敗訊息寫出真正原因。
4. **成本來源只顯示管理者說明**：瑞鼎顯示「取 2026/09/30 當日最低 225.5；明講 240 以下買進。」修改時間與系統原判改寫進判定歷程。舊後端回的長格式，後台與網站畫面也只取說明那一段。
5. 後台右上角帳號按鈕只留圖示；網站頁尾「網站連結顯示「找不到檔案」？」移到技術說明的常見問題（13 題）。
