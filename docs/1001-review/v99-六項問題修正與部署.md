## 人工說明怎麼保留

1. 部署 v99 後，在後台逐日編輯儲存普通逐字稿列，`apiAdminUpdateRow` 會將說明與分類、來源影片 ID、原始逐字稿 SHA256 記在既有「修正建議」分頁，動作是「保留人工說明」，狀態是「已套用（人工說明）」。不新增試算表分頁，也不改交易價、影片 ID 或通知帳本。
2. 只讀當日影片列來取得指紋，不讀回整份歷史逐字稿。Python 覆蓋前把操作紀錄、會員持股及修正紀錄合成一次批次讀取；前台查詢不增加這項讀取。
3. 原文 SHA256、來源影片、股票、當日分類仍一致且只有一筆可對應，才保留儲存的說明。其後公開文字清理照常執行，不能靠人工標記把來源套句放回去。
4. 原文改版、來源或分類改變、同類同檔多筆、說明被直接改試算表或找不到股票，都不自動套用，留下內部「人工說明待複核」。本機測試包含這六種失效情形及第二次重跑。
5. **不推定舊說明是人工版本。** 需要保留的普通逐字稿列，應在新版部署後由管理者確認內容並重新儲存。簡訊／人工補登已有來源保護，這個新機制不取代它們的解析及雙來源補述。

消息保護是針對已發現的增資、繳款、權利金錯接，並不是所有消息面的完整語意證明。股票對應、引句、數字、匿名個股二次稽核仍需照原流程執行。
