# v198 第二階段細節修正

## 八項需求與實作

| 項目 | 採用方式與證據 |
|---|---|
| 副圖價軸 | 本站為Lightweight Charts 4.1.3，未套Chart.js的afterFit或layout.padding。以minimumWidth、alignLabels、entireTextOnly及實際價軸最大寬度同步；亞德客主圖及四副圖價軸96px、繪圖區1132px，縮放後均331.25–404.75。未限制KD到0–100，避免裁掉J線。 |
| 60分K反灰範圍 | 保留可聚焦的aria-disabled狀態。點選／聚焦顯示實際起點與週期建議，標示資料區；有效區間不帶不相關提示。84個交易日只在當次真實資料符合時顯示，不寫死；「全部」資料有效就能選，不刻意停用。 |
| 自訂均線 | 2–1200整數、最多12條自訂，排序及去重；預設均線不被當成自訂刪除。獨立×按鈕、localStorage跨股票與重開保留。實測新增MA120、8.5拒收、瑞鼎重開仍保留、移除後讀數同步消失並回焦＋。資料不足不補出均線。 |
| 流體動態 | 四張統計與全寬持有卡加入低對比雙層SVG水波，離屏／背景／減少動態暫停；與既有訊號帶暫停連動，未新增全域暫停按鈕。數字以650ms位移更新，保留真實數字，不從0補間股價或報酬；圖表資料就緒／範圍切換220ms轉場。 |
| 深色日曆 | 無資料文字為rgb(167,197,192)，日期格不再套低透明度。有紀錄日期保留邊框及2px懸停位移；沒有讓無資料日變成可點。 |
| 維護連結 | 有本次runUrl才標本次；其餘導向真實工作流程歷史。移除「未取得本次網址」，不捏造系統已完成或單次執行紀錄。 |
| 固定表頭／儲存回饋 | 真正table補sticky表頭；逐日及持股已是卡片，保留架構並在編輯時保留股票標頭定位，手機採自然排列。只有實際成功回呼派發掃光事件；獨立資料測試失敗0次事件、成功1次事件，動畫1.1秒。沒有為測試寫正式資料。 |
| 分析骨架 | 首讀有四格骨架與雙環、aria-busy；成功／失敗均收起，更新時保留既有數據。獨立資料實測busy true／骨架顯示，到達後busy false、骨架移除、4張卡依0/40/80/120ms進場。 |

額外修正個股開關與stock查詢參數一致、開啟後焦點進入關閉鈕、Tab在對話框循環及關閉還原焦點。未改分類、來源、報價計算或通知帳本。

## 參考採用差異

原文件Chart.js的afterFit與layout.padding不適用。採用本站圖表API並以真實Canvas寬度核對；價軸對齊設計參考[官方PriceScaleOptions](https://tradingview.github.io/lightweight-charts/docs/4.2/api/interfaces/PriceScaleOptions)。數字動畫保留資料真值，不顯示途中虛構現價；未沿用規格中不合法的CSS @media串接或停用按鈕上收不到的click寫法。沒有恢復已移除的價格水位、觀察窗、教學卡或全域暫停。
