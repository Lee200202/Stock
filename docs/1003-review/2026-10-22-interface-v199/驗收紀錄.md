## API 載入效率（2026/10/22 正式站實測，自 Pages 來源的瀏覽器分頁量測）

| 呼叫 | 冷快取 | 命中快取 |
|---|---|---|
| 個股摘要 apiGetStockSummary | 5.5 秒（Apps Script 5.2 秒） | 0.3 秒 |
| 公司資料 apiGetStockFundamentals | 4.4 秒 | 0.08 秒 |
| K 線 apiGetCandlesBundle（66KB） | 5～8 秒 | 0.1 秒 |
| 報價 apiGetQuotesFor | 3.5～4.8 秒（不快取） | — |

偶發 37～55 秒後回 502（Worker 每次最多等 40 秒、總計 55 秒），面板顯示「K 線載入失敗」。
成因在 Apps Script：`getCachedDailyK` 快取未命中時讀整張「日K快取」並重寫全部代號的快取；
K 線整包在開盤時段還會即時向富果補當天 60 分 K。

本版處理：
- 前台開面板改送 `apiGetCandlesBundle(code, {hour:false})`，選「60分」才送 `{only:'hour'}`；
  後端 `getCandlesBundle(code, opts)` 省略 opts 時照舊整包，舊版後端忽略 opts 仍可運作。
  **效益要等 `/exec` 切到 506 才會出現。**
- K 線後端失敗時自動重試一次；仍失敗給「重新載入走勢」，不必整頁重新整理。

尚未處理（建議）：
- Worker 為 `apiGetQuotesFor` 設 10～15 秒短快取（需另外部署 Worker）。
- 日K快取未命中時只讀該代號，或在讀表期間用旗標讓同時到的請求等待，避免多個請求各自讀整張表。
