## 原因與修正

- 6533 晶心科未在目前持有清單，但公開摘要及行情 API 均回傳 10/22 收盤 282.50、前收 291。平日前端的過期判斷把前次行情隱藏成破折號，並非這筆價格不存在。
- 將「有日期的前次行情」與「當日過期／無行情」分開。卡片、訊號帶與個股抬頭保留前次價及原日期；當日超過五分鐘的過期價仍不冒充即時成交。未知參考價不寫 0%，較舊回應不得覆蓋新價；持有中的即時報酬仍保留原本新鮮度限制。
- 這一回合的走勢：14px 改為 18px；標準／大／特大分別 18／22.5／27px。報酬可另列，不把標題擠到剩一字。
- 回合圖的刻度、日期、價位、持有天數與浮動提示均依設定縮放；切換字級重畫座標及留白，手機圖內可橫滑。K 線及副圖座標基準由 12px 改為 13.5px，同步遵守設定。
- 搜尋輸入與共用表單字體依設定縮放，後台輸入框／選單統一 16px 基準及 16px 圓角。
- 360px 特大字的持股卡日期原本不換行造成 8px 整頁溢出；日期改為可換行，較大字級的手機價位／報酬改為上下兩層，保留完整數字。
