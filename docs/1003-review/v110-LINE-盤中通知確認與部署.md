## 尚待真人確認

待確認的那位好友必須在自己的 LINE 聊天室輸入「開啟盤中通知」，或點「管理訂閱」卡片的「確認開啟盤中通知」。本輪沒有代替好友送訊，也沒有向訂閱者送測試推播；因此 LINE 手機上的最終卡片畫面與該好友的狀態轉換，須在本人實際操作後查看。LINE API 卡片格式驗證通過不等於訊息已送達或已讀。
