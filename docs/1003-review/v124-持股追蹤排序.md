# v124 持股追蹤排序

日期：2026/10/05。Apps Script build `2026-10-05-tracker-sort-v124`（版本 366）。GitHub `0c30185`。只改呈現順序；持股取價、報酬計算與資料表不變。

## 改動

- 前台持股追蹤在摘要與卡片之間多一排橢圓膠囊：獲利、進場日、最近提到（只在「持有」）、出場日（只在「已出場」）、代號。
- 預設依獲利高到低，每次進站都從這個預設開始。按另一顆換依據；同一顆再按一次反向，選中的那一顆帶箭頭（↓ 高到低／新到舊／大到小，↑ 相反）。
- 沒有值的排最後，不論方向：還沒補到價的報酬、代號待確認的代號。同值時維持後端原本的順序。
- 切到另一個分頁時，原本選的依據在那邊不存在（例如持有時選「最近提到」）就回到獲利。
- 後台持股追蹤用同一組膠囊（沒有「最近提到」，後台清單沒有這個欄位）。有未儲存的修改時不重排，並提示先儲存或收起。
- 手機寬度下四顆排在同一行，不必左右滑。
