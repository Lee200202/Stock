| 狀況 | 現行處理 | 效率與完整性 |

| 一次 503 | 下一把金鑰試同一主模型 | 今日第一次實抓已證明能恢復；不將金鑰永久標壞 |
| 可用主模型金鑰全部 503 | 有備援時立即換模型 | 不先浪費 30、90 秒退避；最後模型仍有限重試 |

| 原稿已存在／手動保留 | 沿用既有防覆寫機制 | 晚到的排程與驗收不覆寫正式原稿 |

### 內容品質的具體問題

1. **漏段修復證據：**30 分鐘第二份稿欠缺「原本 3.5、5、6 元 EPS，現在 10、11」、「60 分 K」「MACD」「950 元以上」整段；15 分鐘第三段從上述 EPS 開始，含完整相關條件。
2. **同音股名仍不合格：**15 分鐘稿仍出現「成城／行程」「四星」「奇奇／奇基」「新科」，不能單憑音近自動掛到股票。4916 等可靠代號可供下游核對；不能寫全域替換把每個「行程」都當勤誠。
3. **數字交叉核對：**備援抽段寫「3 元」，正式來源和 15 分鐘稿寫「3.5 元」。兩個模型相同或不同都不是原音真值；需保留回聽待核對。
4. **節目尾聲：**15 分鐘稿到「明天見」；正式原稿另有最後法定揭露段，驗收稿未取得該段。不得因此宣稱所有 56:46 的口白均已完整。
5. **正式前台仍有可見同音誤字：**10/05 逐字稿頁可見「金星科」「星KY」「程成」等；個股結構化卡片則已有勤誠、世芯-KY、事欣科等對應。取稿、公開逐字文字與結構化個股的品質需要分開判斷。

因此今日驗收稿沒有寫回試算表，也沒有重算文章或重寄。現行 pipeline 已有原稿證據、語音名稱候選、代號比對、補漏與幻覺檢查；這些能改善個股結構化結果，仍不能取代原音校聽或修復所有公開逐字誤字。下一步品質改善應鎖定疑義片段，避免每集全片多模型重聽拖慢第一份稿落地。
