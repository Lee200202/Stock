## 判讀流程的改動（`pipeline/pipeline.py`）

都是句型規則，沒有任何一條寫死股名。

| 核對 | 做什麼 | 起因 |
| --- | --- | --- |
| 當日成交 | 原文明講今天賣出／買進的那一檔一定列當日買賣；兩句以上或明講告知會員才改類。第三方（外資、投信、ETF）的買賣不算 | 10/06 鴻海 |
| 覆核移除 | 初稿有逐字原句、覆核卻整檔拿掉時放回；買入的日期核不出來時降為觀望注意，不整檔消失 | 10/06 聯電、10/05 聖暉、達邁 |
| 直白說法 | 沒有分類的台股，原文有「不用追、不建議、沒有推薦、幹嘛去買X」就照原句補列；「先下評語、後報名字」也認 | 10/06 華通、啟碁、漢唐；10/05 創意、聯發科 |
| 說法歸屬 | 否定的話後面緊接股名就是在講那一檔，否則看前面最近的股名；連著念的幾檔算一組 | 「為什麼推薦力積電不推薦聯電」曾把力積電改成不碰 |
| 排除單檔覆核 | 點到名卻沒有任何分類的台股，只給那一檔的段落單獨再問一次；回覆要附段落編號、數字要對得上才收，答 skip 就維持排除。最多一次呼叫 | 10/05 緯穎、10/02 神準 |
| 代號配對 | 「4916，新科」中間隔逗號也配成一組；念出代號的名稱進盤點 | 10/05 事欣科 |
| 買入與持股的保護 | 講者買進或模型判為持股、只因日期或主詞核不出來才降級的列，不再被關鍵字翻成觀望不碰或整檔略過；「賣壓已全數消化」「跌破後量縮不破低」不算負面 | 10/05、10/06 勤誠，10/02 嘉澤 |
| 說明品質 | 補充句不重講同一件事；不用「老師」當主詞；離本股價位帶很遠的買賣價拿掉；補充說明整批不可用時重問一次；說明空白時改用已核對的一句原句 | 嘉澤、世芯-KY、力旺 |

覆核的提示詞加了兩條：初稿有原句的個股要改放排除必須寫出推翻它的那一句；講者明講今天做了的買賣一律是當日成交。

## 同一檔當天另有盤中資料時的說明

- 分類照盤中那一筆。
- 說明的來源順序：當天逐字稿講到這一檔 → 用逐字稿內容（已核對的重寫；重寫沒過時用同日影片那一列已核對的說明，方向打架就不用）；逐字稿沒有這一檔 → 用盤中內容。後台改過的列不動。
- 兩種先後都會補：盤中先到，由每日流程擷取後補（原本就有）；影片先整理完、盤中後到，解析完立刻補（這次新增，原本要等到隔天）。
- 公開文字不寫來源管道的字眼。規則一份兩處：`pipeline.py` 的 `_NOTICE_WORD_RULES`、`scripts/public_narrative_v10.txt` 的 `NOTICE_WORD_RULES_`（由 `sync_quality.py` 同步到 Apps Script 與前台）。公開 API 送出前再過一次；持股追蹤的原始歷程欄位（帶明講價位）不再送到前台。
