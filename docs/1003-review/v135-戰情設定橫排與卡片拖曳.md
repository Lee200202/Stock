# v135 戰情設定橫排與卡片拖曳

日期：2026/10/06。GitHub main `7d7f61f`，Pages 建置成功。Apps Script build `2026-10-06-battle-settings-row-v135`（版本 384，HEAD 已推，待切換正式部署）。只改戰情設定的版面與拖曳，篩選邏輯沒有動。

## 改動

**橫排**
- 跳空方向、均量基準、量能比較原本直排在左邊一欄，右邊三個數值欄位下方空了一大塊。現在三組橫向排成一列，各自對齊下面那一個數值欄位：跳空方向↔最低開盤幅度、均量基準↔最低日量倍數、量能比較↔最低當日量。
- 861px 以上是三欄。721–860px 每欄放不下兩顆選項，三組改成各佔一列（選項仍在同一行），數值欄位維持三欄。720px 以下單欄。

**整張卡片可拖**
- 原本只有條件卡片裡的橢圓按鈕設了可拖曳，抓卡片其他地方沒有反應。現在卡片本身是可拖的：從說明文字、空白處、橢圓按鈕開始拖都一樣，拖著走的是整張卡片，原位變淡。
- 卡片裡的設定區（均線週期、回看週期、收盤位置門檻）從那一區按下時這一次不啟動拖曳，所以週期按鈕照常點選、輸入框照常選字輸入。
- 點橢圓按鈕仍然是加入／移除；已加入的條件標籤也仍然可以拖回清單。觸控裝置沒有原生拖曳，維持點選。
