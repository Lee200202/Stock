# v137 戰情：進場／出場訊號、條件庫、策略範本

日期：2026/10/06。依據兩份規格：[戰情技術設定：完整 AI 實作 Prompt](戰情技術設定-完整AI實作Prompt.md)、[張震選股操作邏輯：來源研究與 AI 實作 Prompt](張震選股操作邏輯-來源研究與AI實作Prompt.md)。
Apps Script build `2026-10-06-battle-signals-v137`。只改前台的計算與設定頁；後端行情 API、排程、寄送、分類、持股都沒有動。

規格很大，這一版完成的是規格自己訂的「第一階段：用既有日 K 能如實計算的部分」。做不到的項目列在最後一節，設定頁上也列給使用者看，沒有用別的資料代替。

## 一、現有資料盤點

| 項目 | 現況 | 影響 |
|---|---|---|
| 日 K | 每檔約 245 根（近 12 個月），戰情 API 一次給最近 160 根 | 120 日均線、120 根位階、120 根帶寬排名算得出來；240 日均線、週月線 MACD 算不出來 |
| 盤中 | 每五分鐘一筆累計報價（開、高、低、現價、累計量） | 當根可用來做盤中觀察；沒有分鐘 K，無法做同時段量比、VWAP、60 分 K |
| 大盤、產業、法人、融資、個人部位 | 沒有 | 相對強弱、族群、籌碼、依成本的停損都不能做 |

## 二、做了什麼

**進場與出場分成兩套條件**
- 設定頁最上面選「進場訊號」或「出場訊號」。兩套各自有條件組、組合方式與方向，分開保存，互不影響。
- 出場訊號是「已經持有時」的風險觀察：不代表有人賣出，不改網站的分類、持股、成本，也不觸發重算或寄送。
- 方向是另一個獨立的設定，只影響原有七個看方向的條件；「向下跳空」不等於「放空進場」。

**條件庫：8 個 → 57 個**
- 分七類：趨勢、突破與支撐、動能、波動與缺口、成交量、K 棒結構、張震觀點研究版。清單預設只列「使用中」的條件，其餘按分類展開。
- 進場 27 個、出場 17 個、兩邊都能用 13 個。完整清單、公式、參數與來源在 `public-site/gas-source/BattleConfig.html` 的 `cfg.conditions`，計算在 `Battle.html` 的 `SIGNALS`。
- 事件與狀態分開：「K 大於 D」是狀態（原有條件），「K 剛上穿 D」是事件（新條件，可選當根／3 根內／5 根內，而且到評估日仍維持）。MACD 的黃金交叉、零軸上穿、負柱收斂是三個不同條件。
- 需要先後順序的規則包在單一條件裡：突破後回測再轉強、低檔大量→量縮→再啟動、假跌破收回、背離（轉折確認→價格確認）。
- 每個條件的數值都在它自己的卡片裡。跳空方向與最低開盤幅度在「開盤跳空」；均量基準、量能比較、最低日量倍數、最低當日量在「爆量與最低量」。新條件各自帶門檻，不借用別張卡片的設定。

**依據標示**
- 每個條件標一種性質：常見指標（28 個，有官方或平台定義）、本站研究設定（22 個，門檻與組合是本站訂的）、張震觀點・量化研究版（7 個，依 168 周報的節目文字紀錄量化）。卡片上附來源連結。
- 張震相關條件與範本一律標「研究版」，說明寫明「數字是本站訂的起點，不是講者的公式」。來源是媒體的節目文字紀錄，沒有逐句核對原片，沒有時間碼。
- 名稱不使用主力、保證、勝率、法人、官方這類字眼（測試會擋）。

**策略範本 29 個**（進場 16、出場 13）
- 本站研究組合：I01 趨勢放量突破、I02 突破後縮量回測、I03 均線承接再轉強、I04 布林壓縮後突破、I06 爆量開盤跳空續強、I07 多頭 RSI 回測恢復、I08 KD 低檔交叉確認、I09 ADX 趨勢啟動、I10 量價確認突破、I12 支撐假跌破收回；O01 結構失守、O02 突破失敗、O03 缺口失守、O04 高檔爆量開高走低、O05 MACD 轉弱加價格確認、O06 高檔背離確認、O07 量價背離加結構破壞、O09 吊燈線獲利保護。
- 張震觀點・量化研究版：JE01 向上季線回測、JE02 低位階均線糾結突破（不含 240 日線）、JE04 低檔 MACD 轉強（日 K 版）、JE06 低檔大量量縮再啟動、JE07 假跌破或底背離後收復、JE09 窒息量後第一根表態；JX01 高位階大量風險、JX02 高檔背離加破位（日 K 版）、JX03 向下季線反彈失敗、JX04 高檔跳空轉弱、JX05 大量 K 失守或突破失敗。
- 範本不另外存：條件組、方向與參數和某個範本完全相同時就顯示它的名稱，改過任何一項就回到「自訂」。
- 全部沒有回測。設定頁與範本說明都寫明「未經回測，不代表勝率」。

**操作與版面**
- 整張條件卡片都可以點（加入／移除），也可以拖；卡片裡的設定與來源連結照常操作，不會誤觸。結果卡片整張可以點開個股。
- 使用中而且有設定的卡片佔整列，設定橫向排開（寬螢幕一列、平板兩列、手機單欄）。
- 結果卡片標示「進場觀察」或「出場風險觀察」與範本名稱；明細照條件組的順序列出每個條件的實際數值（例如「2026/08/17 突破 101；08/18 回測…」）、規則與依據性質。個股頁列出全部條件目前的狀態。

**舊設定相容**
- v136 存在瀏覽器裡的設定原樣沿用為進場那一套；最低日量倍數仍是 1 倍，沒有被改成 2 倍。出場那一套從預設開始（跌破前低 或 跌破 20 日均線）。

**重算速度**
- 240 檔重算一次：Chromium 實測由 434 ms 降到約 90 ms。原因是同一根日 K 的合理性檢查被重複做了幾十次，改成每根只做一次；歷史缺口先看價格再對行事曆。判定結果不變（見驗收第 3 項）。

## 三、指標定義（版本 `2026-10-06.2`）

SMA 簡單平均；EMA 以第一筆為種子；RSI、ATR、ADX 用 Wilder 平滑、前 n 筆平均為種子；KD 為台股 9／3／3 遞迴平滑、種子 50；MACD 12／26／9、柱體 =（DIF − DEA）× 2；布林 20 根、母體標準差 2 倍。前高、前低、均量、位階一律不含當根。
轉折：左右各 3 根；右邊 3 根走完才確認。資料不足（長度不夠、日 K 有缺日、價格不動造成零分母）回傳「資料不足」，不當成不成立，也不當成成立。

第 2 項的內容：
- 登錄表與範本一致：57 個條件都有計算、性質、有效來源；範本只用登錄的條件與允許的參數值；套用後認得出來、改一項就不是範本。
- 34 個條件在 4 組隨機走勢、每組 230 個交易日上，逐日對照「照定義直接寫的算式」，全部一致；每個條件都發生過，也都不是永遠成立。
- 15 個有先後順序或結構的條件各有正例與反例：突破後回測（沒回測、回測破位、回測量沒縮、還沒過回測高點、突破價不漂移）、均線回測 對 向下均線反彈（互不重疊）、假跌破收回 對 續跌、缺口守住 對 當天回補、缺口失守三種程度、底背離與頂背離（未確認不回填、破底作廢、價格確認）、低檔大量 對 高檔大量、量縮但破底、觀察點不漂移、窒息量三種模式、均線糾結（缺 120 日線時是資料不足，不退成三條線）、布林壓縮、反轉 K 棒。
- 不看未來：每個交易日只給當天以前的資料算一次，再給含未來的資料算一次，57 個條件的結果與文字完全相同（5,000 筆以上）。
- 盤中與盤後：同一根用即時報價與用落地日 K，結果相同；需要全日量的條件盤中是「資料不足」。
- 日 K 缺一天：所有新條件都是資料不足。參考價與前日收盤不一致（可能除權息）：整檔不判定。
- 三值邏輯：「或」有一支成立就列出，資料不足的那一支仍標問號；「且」有資料不足就不列；空的條件組不會讓全部股票符合。

## 五、沒有做、不能做的

設定頁「目前還不能提供的條件」列出同樣的內容。

| 項目 | 原因 |
|---|---|
| 同時段量比、開盤區間突破、日內 VWAP | 需要每檔的歷史分鐘成交資料 |
| 60 分 K 的 5／35／200 均線與 60 分 MACD（JE03） | 需要可靠的 60 分 K；不能拿日線代替 |
| 週線、月線的 KD／MACD（JE05）、240 日均線 | 160 根日 K 不足以計算與暖機 |
| 相對大盤／產業強弱、族群輪動（JE08） | 沒有大盤指數與可追溯的產業分類 |
| 法人、融資融券、周轉率 | 沒有資料 |
| 依成本的停損、ATR 移動停損、分段停利、時間出場（O08、O11、O12、JX06） | 需要使用者自己的進場價與部位，本站不保存 |
| Parabolic SAR、Aroon、一目均衡表、Keltner 壓縮（I05）、MFI／CCI 的出場版本 | 這一版沒有實作 |
| 條件樹的 NOT、至少 N 項、跨條件的先後順序 | 沿用兩層條件組；先後順序只在單一條件內部 |
| 方向「不限制」 | 沒有做；方向維持向上／向下 |
| 小型價量圖、突破線與缺口的圖示 | 沒有做；目前以文字列出日期與價位 |
| 公司事件（除權息、分割）的完整核對 | 沒有資料；只在報價參考價與前日收盤不一致時整檔不判定 |
| 回測、勝率、報酬分布 | 沒有做；頁面沒有任何勝率數字 |

已知的限制：
- EMA 類指標以「最近 160 根的第一根」為種子，和從上市第一天算起的數字在尾端會有微小差異。
- 「最近 60 根最大量的那一根」「最近 N 根內最早的突破」這類觀察點會隨視窗往前移而更換；卡片上會寫出是哪一天、哪個價位。
- 盤中的當根尚未收盤，結果是「盤中條件符合」，收盤後可能改變。
- 這些條件的數值正確，不代表策略有效。
