# v154 後台執行連結驗收（2026/10/08）

## 原因與修正

逐日編輯同步卡的 `mLog` 留著 `href="#"`；登入後只替 `fixLog` 和 `fullLog` 寫入 Apps Script 執行紀錄網址，因此點選會回到後台頁首。其他作業連結也有相同的占位網址，雖有部分前端備援，載入到備援執行前仍可能點到無效錨點。

現在所有日誌連結在 HTML 初始狀態就有有效網址：取稿與每日流程到對應 GitHub Actions 工作流程；逐日編輯同步、維護工具和逐天判定到原 Apps Script 專案的執行紀錄。後端回報本次執行網址時仍會替換成該次網址；登入回報的原專案執行紀錄網址也會更新同步卡。今日狀態的兩個外連及各作業連結統一使用橢圓按鈕，焦點清晰，觸控高度至少 44px，手機窄版整列。
