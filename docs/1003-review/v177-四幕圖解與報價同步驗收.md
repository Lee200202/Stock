## 報價問題與修正

10/14 正式站原本開著的首頁仍顯示鴻海 240 / -1.84%，但正式報價 API 09:26 回傳 244.5 / +1.88%，昨收 240。原因是首頁只在初次畫面載入取价，個股頁卻有獨立五分鐘更新；快照較舊也可能覆蓋新資料。正式驗收另發現補查快取只留一分鐘，使每輪最多四檔的補查容易反覆從前幾檔開始。

現採同一報價狀態供每日總覽、行情列、個股、持有中回合使用：

1. 漲跌幅＝（最新成交價－前收盤參考價）÷參考價×100%。無有效參考價显示「—」，不填 0%。
2. 以來源 stamp 比較；網頁補查另存 quote_view_，保留十分鐘但僅在五分鐘新鮮度內採用；不更改五分鐘排程使用的富果六十秒快取，避免排程沿用上一輪而不更新。較舊或無時間的回應不蓋掉有可核對時間的新行情。
3. 工作日 09–15 時、頁面可見時每分鐘批次讀報價 API；轉送層仍使用既有一分鐘快取，後端行情沿用既有五分鐘更新。這不是逐筆即時保證。
4. 正常卡片與行情列不另列時間，成交時間放在滑鼠提示；盤中超過五分鐘時價格與漲跌不顯示，只留待更新；前日行情標明前次日期。移除首頁重複的分類數量段落，比例圖保留可讀的無障礙標籤。切回分頁會重新讀取；請求失敗保留最後可核對值與時間。
5. 持有中的現價與未實現報酬一起更新；已出場回合保留歷史出場價。累積回合報酬維持後端紀錄，不冒充即時重算。
