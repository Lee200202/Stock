## 報價問題與修正

10/14 正式站原本開著的首頁仍顯示鴻海 240 / -1.84%，但正式報價 API 09:26 回傳 244.5 / +1.88%，昨收 240。原因是首頁只在初次畫面載入取价，個股頁卻有獨立五分鐘更新；快照較舊也可能覆蓋新資料。

現採同一報價狀態供每日總覽、行情列、個股、持有中回合使用：

1. 漲跌幅＝（最新成交價－前收盤參考價）÷參考價×100%。無有效參考價显示「—」，不填 0%。
2. 以來源 stamp 比較；較舊或無時間的回應不蓋掉有可核對時間的新行情。
3. 工作日 09–15 時、頁面可見時每分鐘批次讀報價 API；轉送層仍使用既有一分鐘快取，後端行情沿用既有五分鐘更新。這不是逐筆即時保證。
4. 卡片與行情列顯示行情時間；盤中超過五分鐘或前日行情明確標示。切回分頁會重新讀取；請求失敗保留最後可核對值與時間。
5. 持有中的現價與未實現報酬一起更新；已出場回合保留歷史出場價。累積回合報酬維持後端紀錄，不冒充即時重算。
