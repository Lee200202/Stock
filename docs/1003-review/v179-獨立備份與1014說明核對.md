## 分類邊界

| 證據 | 分類與處理 |
|---|---|
| 當天通知已有本股動作 | 通知分類優先；影片只補本股說明 |
| 明確部分賣出，剩餘部位續抱 | 同日賣出與持股可以並存；不整檔關閉回合、不猜剩餘張數 |
| 未全數賣出的買入紀錄，或近期持股紀錄 | 與當天原文相符才列持股；後續全出則結束 |
| 觀眾提問「我有」，回答續抱 | 屬觀眾自己的部位；列觀望注意，不當成網站持股 |
| 無部位，但有買點、等待條件、向前看的本股訊號 | 觀望注意，不要求當天已成交 |
| 名單共用明確的「這類／那種股票不買」 | 原句範圍內的同組標的列觀望不碰；不得越過轉場或套到另一份名單 |
| 只有漲跌描述，沒有當下立場；已出場的獲利回顧 | 不新增公開觀望或當日成交 |

共同否定不是全面調整觀望門檻。程式排除條件句、過去式、雙重否定、其他人的說法、轉場及單數受詞；通知、人工裁決與已存在的持股證據仍優先。裁決版號更新，舊的排除票不能壓過已核對的原句。
