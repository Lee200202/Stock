# v183 分類定義與裁決圖卡

## 內容與行為

- 原「交易主體與分類」章節保留相容錨點 `tech-subject`；新增六類膠囊按鈕、帶顏色與文字的獨立卡片。每卡以四個有編號的階段呈現人物／部位、日期／條件、動作及結果。
- 買入、賣出、會員持股、觀望注意、觀望不碰、不公開，各有一個明示為虛構的甲股句型與兩條邊界。沒有展示私人通知價位或假裝查詢正式帳戶。
- 投票圖有五個可選情境：第一票相同、兩票改觀望、一般三票改持股、沒有有效證據、成交候選複核。圖中一至三張票有勾選／叉號、序號與文字，不只用顏色區分。
- 三輪是每次流程的上限，不是全日上限，也不是三位獨立專家。直接證據先處理；至少兩張可用票一致的特定補收例外、無效票與單檔隔離另有可展開說明。
- 在「先看重點」與完整模式都能閱讀。捲到時只循環強調當前定義的四個階段，不自行改變分類；點選定義或票數情境停止，按「再播判定」重新循環。離開畫面或分頁隱藏會暫停；減少動態時不播放。
- 全程本機互動，不呼叫模型、網站 API、工單、行情或寄送。沒有 JavaScript 時六類規則與一般投票門檻仍直接可讀。
