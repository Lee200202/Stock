## 缺口

1. **雲端排程的兩個變數。** 主表從未換卷時不影響。換卷後兩個雲端排程（11:40 寄信前複核、週五檢討）需要 `APPS_SCRIPT_URL` 與 `ADMIN_KEY` 才查得到使用中的一卷；值與 GitHub secrets 相同，由管理者貼在 claude.ai 雲端環境。
2. **GitHub 失敗沒有人判斷、也沒有 LINE 通知。** 失敗會寫進「系統狀態」，但只出現在狀態信與後台頁面。當天最後一輪也失敗時，沒有任何機制決定要重跑、修程式，或通知管理者。
   - 當「系統狀態」本身寫不進去時（容量、429），狀態信也看不到這次失敗。

自主事故處理流程（補缺口二）見同日提案，管理者同意後才建。
