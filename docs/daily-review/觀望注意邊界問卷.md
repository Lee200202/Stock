## 二、管理者描述的「觀望注意」與候選說法

管理者的描述：分析師沒有實際買進，但這一檔值得好好注意後來的成長性；或者「現在賣掉就是砍在阿呆谷」。

### 觀望注意的候選說法（講者的語氣）

| # | 類型 | 原稿裡的說法（例） |
|---|---|---|
| 注1 | 點名為之後要買的 | 「我未來等大環境回穩，我會買的記憶體就是這支股票」（宜鼎 11/03） |
| 注2 | 給了買點／價位 | 「台積電，如果你們運氣好，有2280，你們就去買吧，我不會擋你們」（11/03） |
| 注3 | 技術面已轉好，先做功課 | 「已經背離的是台積電…聯電也背離了…這些股票先留下來做功課」（11/03） |
| 注4 | 看好但還沒買 | 「不是世芯-KY不好，我不買，我也想買啊…我都流口水了」（11/03） |
| 注5 | 持有者別殺低（阿呆谷） | 「130以下，不準賣聯電…我沒有聯電」（10/20） |
| 注6 | 打底中，別亂殺 | 「不要亂殺台達電？台達電現在要來回震盪打底，我沒有買台達電」（10/28） |
| 注7 | 這一波對的股票、還會上去 | 「鴻海，是這一波對的股票…240以下你就是給我買就對了」（11/03） |
| 注8 | 便宜、可以注意 | 「傳產股便宜的還有這一支叫東元」（11/02） |
| 注9 | 指標股，要盯著看 | 「記憶體看兩隻股票…第一隻叫8299群聯…另外一隻…宜鼎」（11/02） |

說明欄可以這樣寫（書面語、只用原稿內容）：

- 「講者尚未買進，但點名為大環境回穩後要買的記憶體股；目前不急著進場。」
- 「講者提出的買點是 2280 元，價位到了才考慮；未到前不追。」
- 「技術面已出現背離，列為大環境回穩後的口袋名單。」
- 「講者未持有；提醒已持有者不要在 130 元以下殺低，等成熟製程止穩。」

### 觀望不碰的候選說法

| # | 類型 | 原稿裡的說法（例） |
|---|---|---|
| 不1 | 明講不碰、剔除 | 「我現在剔除群聯，我不碰群聯」（11/03） |
| 不2 | 明講不買 | 「我不會碰大立光」「大立光、聯發科，目前我都不碰」（10/28、11/03） |
| 不3 | 預期還會跌，跌破才考慮 | 國巨「跌破前禁止會員與投資人買進半張」（10/30） |
| 不4 | 結構性風險（缺口、斷頭、散戶太多） | 「聯發科…我會怕這個缺口…不可能在那邊去賭」（10/28） |
| 不5 | 長期不碰的族群或個股 | 「矽晶圓族群…長期不准碰」、宏達電「退休前絕對不會買」（10/30） |
| 不6 | 被問能不能買時答「還沒有」 | 台達電「跌停可以買了嗎？還沒有…還要等」（11/02，已裁示不碰） |

### 先提出、請一併確認的原則（草案）

- **大環境的等待不算個股的禁令**。講者說「大環境還沒穩，先不要進場」時，這句話適用所有股票。單憑這句不能把個股變成不碰，要看他對這一檔本身的態度。
- **個股本身態度正面就是注意**：點名要買、給了買點、技術面轉好、看好、叫持有者別殺低。就算後面接著說「等大環境」，也還是注意。
- **個股本身態度負面才是不碰**：明講不碰、不買、剔除，預期還會跌，或點出這一檔自己的風險。

## 三、情境題（請勾選；可在備註欄補一句理由）

### A. 買點已到或技術面轉好，但「等大環境」

**A1｜11/03 台積電｜網站：觀望不碰**
> 「台積電，如果，你們運氣好，有2280，你們就去買吧，我不會擋你們。」「除非有2280，否則，就不用再問我。」

初判：注意（注2，給了明確買點）。
☐ 觀望注意　(管理者確認)

**A2｜11/03 世芯-KY｜網站：觀望不碰**
> 「不是世芯-KY不好，我不買，我也想買啊，世芯-KY跌破3,300，你知道嗎？我都流口水了…啊為什麼我還不碰？是因為…大盤…我還沒辦法下手」

初判：注意（注4）。但原句有「我還不碰」，和 11/02「還不敢碰＋要等＝不碰」的裁示字面相衝。**這題最關鍵**：「還不碰」的理由如果只是大環境，算不算不碰？
☐ 觀望注意　(管理者確認)

**A3｜11/03 台達電、聯電｜網站：觀望不碰**
> 「已經背離的是台積電…聯電也背離了…大環境穩了，這些股票先留下來做功課，聯電，台達電，功課先做好，等到大環境一起來，就往這邊跑」

### C. 等回穩或條件未達

**C1｜11/02 群聯、宜鼎｜網站：觀望不碰**
> 「記憶體看兩隻股票。這兩隻股票還沒有回穩之前，記憶體你不要碰…我只要你看最龍頭的兩隻…這兩隻都沒有漲，那你就不要亂買」

初判：注意（注9，兩檔是要盯著看的指標）。「不要碰」講的是整個記憶體族群，等這兩檔回穩才進場。
☐ 觀望注意　(管理者確認)

**C2｜11/02 台達電｜網站：觀望不碰（11/02 已裁示）**
> 「跌停可以買了嗎？還沒有，還沒有，一定要用60分K線看…所以台達電還要等」

已裁示為不碰。請確認和 A3（隔天說背離、先做功課）不衝突：同一檔可以前一天不碰、隔天注意嗎？
☐ 維持不碰（A3 照勾選另判）(管理者確認)

**C3｜聯發科：10/28 vs 10/30｜網站：10/28 不碰、10/30 注意**
> 10/28：「聯發科不買…因為聯發科這個缺口補了…我會怕這個…所以我不可能在那邊去賭萬一下來」

初判：兩天都是不碰（不4，講的是這一檔自己的缺口風險）。
☐ 兩天都不碰　(管理者確認)
