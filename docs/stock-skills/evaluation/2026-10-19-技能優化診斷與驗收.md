# 技能優化診斷與驗收

日期：2026/10/19。範圍：技能、參考規格、離線工作手冊與評估工具；未改分類程式、正式資料或網站部署。本輪模型 API 請求 0、Email／LINE 寄送 0。

## 一、結論與處理

目前可以建立可信的離線評估，但既有「預覽全過」不足以證明模型獨立品質。已更新五個技能，維持九個任務入口，並新增共用 A/B 評估參考文件。這次完成規範與工具驗收，尚未取得真實模型 A/B 改善幅度。

| 診斷 | 實查證據 | 處理 |
|---|---|---|
| 評估混入人工資訊 | `regenerate_verified_day.py` 的預設預覽注入答案；`rules-only` 仍可採人工說明與禁止文字清理；`raw` 仍會讀既有裁決 | 明列獨立／人工輔助／元件測試，凍結並隔離裁決快取 |
| 樣本不可只看答案日 | 正式 `apiListTranscriptDates` 回傳 67 天，答案檔僅 13 天 | 建完整歷史語料清單，54 個無答案日列待標註，不將 AI 初標當黃金答案 |
| 多次重跑易高估樣本量 | 同一集的多檔與重跑共享來源及批次 | 日期／事件為群聚，逐檔與逐日分數分列，沒有計算虛假 p-value |
| 標籤驗收與部位混淆 | 管理者接受持股／注意同組，但不能據此推導部位 | 保留 accepted 驗收政策，另外列 strict 診斷；交易與帳本仍各自核對 |
| 舊文字技能與最新裁示衝突 | 舊規格要求詞表或動詞命中直接刪句；程式仍找到 `_REPORTING_LEAD` | 技能改為整批 AI 語意審閱；正式程式是否仍走舊路徑列待查，未宣稱已修 |
| 全版標準不明 | 個別頁獨立加寬會與其他分頁不一致 | 以共用容器、同設定左右邊界及字級縮放驗收 |
| 自製按鈕易失去可用性 | 視覺樣式不能代替控制項語意 | 補原生 radio／checkbox 的自製外觀範例、焦點、鍵盤與高對比要求 |
| 動畫需求被過度泛化 | 技術圖解要求循環，統計圖重複閃動卻干擾數字閱讀 | 技術圖解與數據轉場分工；減少動態與離屏處理保留 |
| 額度與重置時間寫死 | 舊規格固定 15 RPM／500 RPD、台灣全年 15:00 | 按當時專案／模型／層級查證，太平洋午夜按 DST 換算，不靠換 key 擴額 |

## 三、完整歷史資料與擴充順序

唯讀清單實查：

|---|---:|

| 2026/08 | 21 |
| 2026/09 | 19 |
| 2026/10（至 10/16） | 11 |

顯示文字合計 1,228,249 字；這不是模型 token，也不是已逐篇讀完的原稿字數。清單可能指向閱讀校正版。13 天已有答案，其中 4 天含核對說明、8 天允許多分類；其餘 54 天只是尚未建答案，不能稱沒有資料。

完整清單、影片 ID、字數、既有答案與暴露狀態：[語料盤點 JSON](2026-10-19-corpus-inventory.json)。清單讀取失敗時不補假日期；本輪成功讀取後才建立此檔。

後續實驗順序：

1. 從 7–9 月無答案日期分層選入不同行情、原稿長度及通知情況；取得保存原稿與指紋。缺稿才走既有 AI 轉錄補取，避免重複花費。
2. AI 批次初標公司／主體／日期／交易事件／部位／立場及來源位置；逐處核對引句與身份，人審爭議和抽樣。每批報已取稿、初標、核對、未定、待處理數。
3. 回歸集、開發集、未見保留集按日期分開。未知是否曾被其他工作階段使用的日期不能直接聲稱未見，先記暴露未知。
4. 通過確定性檢查後才執行凍結 A／B 的唯讀比較；模型請求、裁判、重試與自動流程保留量一起算預算。不是一次重跑全部 67 天，更不是 13 天上限。

本輪完成的是清單盤點與擴充規範，54 天尚未新增人工答案，也未執行歷史模型分類。

## 四、參考資料如何採用

- [管理者指定 AlphaLab 文章](https://www.alphalab.site/agent-skill-routing-ab-test) 作為路由評估議題索引；其研究數字不當本站成效。原始研究另核對 [Demystifying Agent Skills](https://arxiv.org/abs/2608.14036)。
- [管理者指定影片](https://www.youtube.com/watch?v=rZl_3izD8y8) 已透過瀏覽器取得字幕並完整讀完。採用有／無技能盲測、描述觸發、區分能力補強與流程偏好、模型更新後重測的方向。影片提及的百分比沒有原始紀錄供本輪驗證，未套成本專案結果。
- 影片提到的工具已交叉確認 [Anthropic 官方 skill-creator](https://github.com/anthropics/skills/blob/main/skills/skill-creator/SKILL.md) 與[盲測 comparator](https://github.com/anthropics/skills/blob/main/skills/skill-creator/agents/comparator.md)。本機使用 Codex 的 system skill-creator，並非同一套件；未安裝或假設 Claude CLI 可用。
- [Anthropic agent evals](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents) 支持區分任務、trial、評分、軌跡與環境結果；模型自稱成功不等於工具真的完成。
- [LLM 裁判原始研究](https://arxiv.org/abs/2306.05685) 提醒位置、長度等偏差，規範加入匿名、順序互換與人審校準。
- [Microsoft 實驗前規劃](https://www.microsoft.com/en-us/research/articles/patterns-of-trustworthy-experimentation-pre-experiment-stage/) 用於分流與樣本單位；[Google 額度文件](https://ai.google.dev/gemini-api/docs/rate-limits) 用於專案額度及重置時間核對。

「100 題」「50/50」「p<0.05」「換更強裁判」都不是不分情況的必要步驟。現階段適合離線成對與唯讀 shadow；正式分類對外只發布一份核定內容。UI 線上 A/B 還需要 experiment／variant／exposure 事件、固定分組及足夠流量，不能拿既有 RF 或停留資料倒推因果。

## 五、驗收證據與限制

| 檢查 | 結果 |
|---|---|
| 九個 skill 的 frontmatter 格式 | 9/9 通過系統 `quick_validate.py` |
| 版本化來源與安裝副本 | 追加自行分類規格後，20 個 Markdown 檔案 SHA-256 一致 |
| 手冊建置 | 追加後 21 個來源 Markdown，21 個閱讀區塊；評估與自行分類文件都有收錄 |
| 本機彙整工具 | `scripts/compare_skill_trials.py`；無網路／模型／正式寫入邏輯 |
| 合成測試 | 8 項通過：成對統計、群聚平均、硬傷、缺組、重複、來源／版本／rubric 漂移、未知用量、單次無法量變異、資料集混用及保留集分列 |
| CLI 實跑 | 合成 manifest／JSONL 成功產生報告，明示 synthetic、未計顯著性與需人工審閱；非模型改善結果 |
| 瀏覽器手冊 | 766px 規則入口與相對連結；390px 深淺色、搜尋、展開與新增規範區檢查，無整頁水平溢出 |
| 大桌面檢查 | 本輪 viewport 設定未取得要求的實際寬度，未計入驗收；沒有冒稱全站或 1440px 已驗 |
| 正式系統 | 只讀公開逐字稿日期清單；未改正式站、分類、Apps Script、Worker 或寄送帳本 |

彙整工具信任外部已評分紀錄及提供的指紋，不能自行驗證原文真偽或 grader 正確性；它不替代人工標註，不計 p-value，不自動判斷可部署。語意變異需以正規化的分類／事實決策雜湊比較，不能用整段文案字句不同當分類不穩定。缺 token 顯示未知，不算零；各 provider token bucket 可能重疊，不盲目加總推理與輸出。

本輪沒有真實 A/B 兩組模型試驗，因此不報「準確率提升 X%」「省 Y% token」或保證未來不再幻覺。已完成可重用方法與本機工具，正式程式的遺留問題及歷史標註依上述流程分批處理。

## 六、追加：沒有答案也沿用同一分類標準

管理者追加要求：不能因歷史日期沒有答案，就失去既有 13 天已確認的分類依據。已補入 `stock-content-audit` 的 [自行分類工作模式](../skills/stock-content-audit/references/self-classification.md)：

- 定義、正反例及 accepted 政策沿用；本股原句、當日操作、截至目標日的部位重新確認。舊日標籤與後來持股不可移植。
- `independent_review` 先交逐檔事實與分類，保存初判後再對照流程候選聯集；已看過目標結果就揭露暴露，不稱盲分。
- `golden_draft` 產生待核對答案，不把同一次 AI 的初標與自評當人審真值。`unknown/needs_review` 與確定排除分開。
- 固定選項區分公司、主體、事件日期、動作性質、當日事件、部位、進場立場與處置。公開五類加內部不公開處置；部分出場、餘部續抱及暫不買回可分軸保留。
- 補必填交付表、可解析 JSON 範本與批次指令；模板預設未審核、無分類、待核對，不能當正式寫入內容。

追加驗收：九個技能格式及 20 檔安裝同步通過；JSON 模板解析、未填模板不預設分類、手冊收錄及引用確認通過。此輪只更新工作規格與模板，未執行歷史模型分類或正式資料更新。
