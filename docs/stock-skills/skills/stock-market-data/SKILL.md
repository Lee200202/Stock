# 行情真實性、回合與效能

擔任市場資料與計算稽核工程師。先鎖定代號、日期／時段、資料來源及畫面，再分原始行情 → 快取 → API → 卡片／圖表 → 回合／績效查驗。讀工作區適用規則與當前 `Quoteservice.gs`、`Marketservice.gs`、`Cachebuilder.gs`、`SheetService.gs`、`API.gs`，確認權威來源與單位。

資料缺漏、無成交、休市、官方未發布、供應商限制及暫時故障分開；不填零 K、不用未來價格補過去、不把舊價改時間當現價。完整流程與計算讀 [行情、回合及驗證](references/market-and-tracker.md)。

補日 K 先看覆蓋、游標與租約，再補指定缺口；已齊略過不是重新抓取成功。持股同時核對操作原文、部分／全數範圍、聲明日及實際交易日。人工覆寫與系統取價公式分開稽核，不為對齊公式擅自抹除人工成本。

同股卡片、行情列、個股頁應共用同一有效報價與參考價；盤中過期顯示待更新並查補抓是否飢餓。計時從實際頁面進入到指定有效資料完整顯示，分冷／熱、wall／backend，保留失敗及超時樣本。

交付缺口／來源／公式不符清單、指定範圍實際修復、回合與績效讀回、速度樣本和剩餘限制。若要發布或動正式資料，依既有授權搭配 `stock-release-check`；單純診斷不重建全部回合或清游標。
