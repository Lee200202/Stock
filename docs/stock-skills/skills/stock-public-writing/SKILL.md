# 公開文字與書面說明

擔任書面編輯。這個技能只管「字怎麼寫、哪些字能出現在哪個通道」；分類對不對交給 `stock-content-audit`，版面與動畫交給 `stock-site-design`，規則怎麼改與怎麼證明交給 `stock-rule-tuning`。

先確認這段文字會出現在哪個通道（公開前台、每日信、LINE、後台、已同意收盤中原文者）與哪個欄位（個股說明、盤勢①、教學③、標題、介面提示），再讀 [書面規格與批次審閱](references/writing.md) 對應章節：通道與可見性第 1 節、個股說明第 2–3 節、數字與時間第 4 節、重點與標題第 5–6 節、介面文案第 7 節、程式關卡與驗收第 8–9 節。

核心要求（管理者反覆強調）：**要有資訊與具體技術面說明，勿口語，勿把逐字稿原句直接放進來，要整理過再寫**。說明以本股結論開頭，接本股的技術位置、量能、籌碼、基本面或題材，再寫條件與風險；材料只有一句時可以短，不湊字、不借鄰股或大盤的話。

公開前台與每日信不出現會員通知的存在與用詞（簡訊、盤中通知、會員通知），只呈現分類；通知成交價只留後台與已同意收件者。任何人的電話、Email、訂閱名單都不出現在公開文字。

文體、口語、錯字與修飾的語意判斷合併 AI 批次審閱，不用逐字黑名單或正規式決定刪句；原句、公司身分、主體、日期、數字、通道隱私及部位核對保留。歷史錯例是審閱 rubric，不是重新建詞表。對既有人工核對說明有疑點先留審閱紀錄，不直接覆寫。合批保留 case ID 與本股範圍，缺答、截斷或改掉事實者不能採用。

改動先用通用正反例及已發布說明回歸，不針對單一股名；few-shot 與評分集分離並檢查照抄。以 `print_public_texts` 與受影響介面逐則讀回驗收，不能用 AI 自評或句子變長代替依據。A/B、盲審及預算見 `stock-rule-tuning/references/evaluation.md`。
