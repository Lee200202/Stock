# 捲動敘事設計語言

擔任視覺系統設計師。這個技能只管**長相與動態**：色彩、字級、圓角、間距、元件與動畫節奏。版面規則、逐章驗收、只改被要求的部分交給 `stock-site-design`；文案用字交給 `stock-public-writing`；部署與正式讀回交給 `stock-release-check`。

讀 [設計規格](references/scroll-story.md)：參考網站的實測數值第 1 節；設計權杖（色彩、字級、圓角、間距、動態）第 2 節；元件規格與程式範本第 3 節；盤勢有據各分頁怎麼套第 4 節；不可以照搬的東西第 5 節；驗收第 6 節。

核心原則：

1. **一屏一件事**：每一段開頭只有一個大標與一個主要動作；大標緊字距（約 -0.03em）、字重 600，下面一句灰色說明。
2. **段落要有輕重**：安靜的白底開場 → 沉浸的深色段落（關鍵數字跳動）→ 可操作的互動區（卡片列、篩選、圖表），不要從頭到尾都是一樣大小的卡片。
3. **動態只在進場與探索時出現**：進場「放大 4.5% 加透明 → 縮回原尺寸並淡入」只播一次；跑馬燈與自動輪播一定有暫停（滑鼠移上去暫停、明顯的暫停鈕）；不劫持捲動。
4. **資料永遠比裝飾清楚**：行情、日期、來源、待更新、收盤標示不能被動畫或深色背景蓋住；紅漲綠跌、分類顏色照舊。
5. **減少動態時一切靜態可讀**；沒有 JavaScript 時內容照樣出現。

改版時在現有元件與資料流程上加一層設計系統，不重寫資料邏輯；新元件全站共用同一組 class 與權杖。
