## 規格的人工邊界核對

| 情境 | 技能應導向的處理 |
|---|---|
| 只請整合 skills | 更新技能與文件，不發動網站／模型／通知 |
| 「如果想買，甲股可以買」 | 注意建議，不憑動詞新增成交 |
| 「今天賣甲股很蠢」 | 核對否定／批評，不算今日完成賣出 |
| 部分賣出、剩餘續抱、暫不買回 | 交易範圍與進場立場分開，不全關回合 |
| 有效前瞻條件但無可用模型票 | 按可直接核對的證據保留注意，不一律漏收 |
| 原稿指紋失效 | 停止對應正式寫入，不以「不中斷」硬通過 |
| 新版已 create-version，原 ping 舊 | 不宣稱部署成功，查原部署及傳播 |
| 已齊略過全部 K | 誠實報已齊／略過，不捏造抓取成功數 |
| 圖解按再播 | 恢復循環；手動切換停；減少動態不自播 |

上表是對文件內容的人工推演，不是新模型行為實驗。沒有因本輪技能更新重新證明歷史分類、正式 quote 效率或下一交易日通知結果。

## 後續維護

以 Markdown 技能來源修改，再重建 HTML、同步原安裝、重跑相應檢查。新規則納入對應領域，舊案例保留日期；勿把某日版號、測試總數、額度或股票分類固化成永久指令。若獨立改原安裝，先比較差異後合併到版本化來源，避免下次 `--install` 蓋掉未收錄的新規則。
