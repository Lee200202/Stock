# 分類裁決：判斷基準與定義


> 現行規範（2026/10/16）：以下「現行決策順序」優先；後面的分日期內容是設計與回測歷史，不能把早期「任何錯誤不擋」解讀成所有錯誤放行。

## 2026/10/27 ph6候選補充（尚未正式合併／部署）

本輪新增「本股獨立分析」事實欄位及原句：有向前位階解讀、量價／風險判斷或低接操作節奏，雖無本人新買意願仍可觀察，不必捏造偏多。只有漲跌報數、碰均線圖例或未持有名單不算獨立分析。實際暫不進場／禁止及會員交易、持股事實仍優先。期待分類僅推論後評分，沒有原句不靠關鍵字補判。此為候選定義，不能視為已通過全日驗收。

未核附加主張只能留內部；保留的已核實子句還需新的語意／分類審閱，不能只改supported與hash宣布整份通過。詳見[ph6核對](1003-review/2026-10-27-pipeline-report/ph6核對與工作流修正.md)。原GAS526狀態與候選來源更新分列，不自動部署或寄送。

## 現行決策順序

1. **來源與身分**：固定日期、影片ID與原稿指紋；先核對名稱與相鄰代號，代號存在不等於名稱配對正確。日常詞、公司比喻、未點名的匿名標的不猜公司。
2. **核實操作語意**：當日通知優先的是完整原文支持的執行指令，不是錯誤解析。本人／會員、日期、肯定／否定、已執行／建議／條件逐一核對；今日無動作不產生買賣。
3. **部位與新進場立場分離**：紀錄上的未出場部位或本股明講持有支持會員持股；觀眾提問、假設句與「我沒有」不建立部位。部分減碼後，剩餘持股與暫不買回可並存，兩列各寫自己的事；只有全出才關閉回合。
4. **當下立場**：本股可買／低接／等待買點與向前技術條件支持注意；現在不碰、不能買、條件尚未出現或暫不買回支持不碰。只報行情、歷史或類比可不公開，不能因希望多收而補立場。歷史出場不阻止評估今天另外提出的買點。
5. **批次AI覆核**：句型直接判讀的語意列集中一問，檢查是否本股、原句是否支持；明顯不支持才送既有多輪事實問卷。硬紀錄與已核實通知不交模型重擲。問卷每輪合併候選，三輪為單次流程上限，不是三位獨立專家，也不是每天只能三問。
6. **逐字證據與定案**：模型只回答事實並附本股原句；程式驗引句、主體、日期與否定。一般同類一票可停止、觀望互換兩票、跨部位等三票一致；例外依程式驗證。證據不足不憑投票創建買賣。規則版與段落指紋變更，舊裁決不沿用。
7. **書面說明**：分類後才寫，本股結論、技術依據、條件與風險分句整理。數字、主詞、時間、因果與部分／全出須對回本股證據；不借鄰股、大盤或匿名標的。不把「否認賣」換成「否認買」，不拿60字截斷句子。
8. **發布及後續寫入**：個別硬傷留底隔離，其餘可發布；原稿失效、無來源或寫入一致性失敗則停止。寄信前補漏遵守主流程已有裁決，不另建互相打架的分類；模型等待後重新驗列身分。單日更新先備份，保留通知帳本與已寄送旗標，前後台及文章讀回後才結案。
9. **驗收等價不是交易規則**：管理者允許持股／注意、歷史負面回顧／不碰作同組內容驗收，寫在答案檔；不能將注意變成真實部位，也不能強迫所有歷史負面例子公開。不能宣稱模型未來零誤判；已知錯誤必須有可重現反例、保留日檢查及正式證據。


### 10/21 來源審核補充：部位、現況與可引用範圍

下列是來源審核的判斷標準，不代表當前模型已全部通過；真實重播、候選版本與正式修復分列在當日驗收報告。

| 證據組合 | 判斷 | 不得推論 |
|---|---|---|
| 昔日已出場，今天再次肯定某承接區並分析目前回升 | 以今天觀點評估注意；歷史交易保持原日期 | 不能僅憑帳本已賣出，就宣告今天只有回顧；不能新增今日買回 |

| 只有「不要殺低」，沒有可歸屬本股的向前判斷 | 核對是否單純教學，不自動升格 | 不准賣不等於不准買；禁止賣出也不證明本人持有 |

| 同名單股票今天走弱，講者用它們明確警示追強風險 | 可列本股風險例；須保留當下行情與共同風險的證據 | 只有歷史成功案例、族群點名或漲跌報價仍不足；「昨天是賣點」不是今天賣出 |
| 同段先講較弱，隨後明講小股本、拉升較快 | 完整讀讓步句及後續預期，按本股判斷 | 不只取「弱」判不碰，也不借給下一檔 |
| 原始聽打與閱讀稿的公司、價位不一致 | 回原稿與相鄰代號核對；未確定保留待核，不公開推定值 | 閱讀稿是加工輸出，不是第二個獨立證人；不能把模糊2959自行修成259 |

數字還須驗證關係：2,490高於2,425，稱作上方缺口；「預期回補」不可改成「已回補」。逐字引句確實存在，只通過存在性檢查，不代表主體、方向與確定程度都正確。既有持股資金尚未騰出，不能寫成等待買回的股票仍有部位。

診斷依序標出候選是否建立、相鄰共用條件是否送入、事實題是否完整、引句是否屬本股、可用票與反對票、收尾或發布是否移除。缺答與無效引句屬未完成覆核，不能統稱「無看法」；也不能為補足數量直接公開未核實內容。

「帳本顯示已賣出」是可核實的部位紀錄；「因此今天只是回顧」另含語意推論。後者應納入既有直接歸類批次覆核，不能借硬紀錄身分跳過現況檢查。10/21 已建立此路由的獨立候選實驗；是否採用以真實重播與回歸結果決定，不以網頁已修好作證。

2026/10/08 建立，後續更新以現行決策順序及各次驗收狀態為準。程式在 `pipeline/pipeline.py` 的「分類裁決」區塊（`adjudicate_classes`、`verdict_class`、`verdict_settle`）；題目是 `ADJUDICATE_SYSTEM`。題目或決定順序一改，就換 `VERDICT_VERSION`，舊裁決不再沿用。

### v19：否認部位不建立觀點；已審閱語意不再被詞表改壞

- 本股沒有持有、問卷又無有效當下立場時，不預設觀望注意。只有另有本股當下條件才能保留相應觀點；沒有條件就不列。這補上v18雖阻止持股誤列、仍可能多收注意的缺口。
- AI批次審閱的四項確認綁定改寫文字與原稿指紋。後續因果用詞篩選不再蓋過這份有效語意確認；文字或來源變動便失效，不可拿舊審閱結果作通行證。公司身分、數字、證據及寫入檢查仍保留。

### v18：否認部位與AI批次文體審閱

- 本股「沒有持有」必須在任何自動升格成持股之前核對；不能在前一分支直接返回而跳過。最後套用裁決再檢查一次，不能用鄰句「這是我的」蓋過本股否認。沒有持有不等於禁止買進，其他觀點另判。
- 直接判定的AI覆核提供所有已選相關段落，不再只給拼接後的前600字；附本股否認原句，讓模型能看見支持與反證。
- 移除文體問句、語助詞、人稱、俚語與買賣措辭詞表；每輪一個AI請求，同時審閱全部個股說明、盤勢與教學。已是書面文字也送審。標題沿用其獨立AI生成與證據核對。
- AI逐筆回覆語意保持、分類一致、本股來源支持、書面品質四個布林值及具體問題；四項都明確true才採用改寫。程式只額外核對數字、公司身分、輸出範圍及儲存一致性，不用文體詞表改分類或刪點。
- 人工保存文字送審但不自動覆寫；AI有疑點就留紀錄。未回覆、格式錯誤或超時維持已核對資料並留下待審閱，不虛稱已過AI審核，也不逐檔反覆呼叫。
- 教學仍以三個不同且有證據的重點為補問目標；若只能保留兩個，列完整度提醒，不湊數阻擋整天。少於兩個仍屬章節不足；無來源、矛盾與重複等品質關卡不放寬。

### v17：分類之後的寫入也必須遵守決定

- 有證據且已強制定案的直接歸類，也保存到分類裁決表，供寄送前補漏讀取；其事實紀錄不當成模型投票。只記模型票而漏存直接決定，會使下游把已排除的股票當成未判過。
- 補漏按原稿相鄰代號與名稱共同找既有決定；原稿或裁決表讀取失敗，不新增分類，留下待處理原因。讀不到不等於沒有裁決。
- 書面說明按「原稿指紋＋代號＋分類」保留。同一檔部分減碼後的續抱說明，與已賣部分暫不買回的說明分開；來源或分類變更不得盲目沿用。
- 不用重跑整天的方式修幾句文字。已逐句核對的書面說明先備份再局部更新，核對非說明欄位及寄送帳本未變；正式資料更新與唯讀模型重播分開驗收。

| 「像我剛才講的敦泰一樣…我不會買的股票是什麼？我絕對不會買它…我不買國巨的原因」 | 「我不會買它」算給前面的敦泰 | 禁令不在股名那一句、用「它」或「我不會買的是什麼？」引出、三句內報出另一檔：不算本股 |
| 紀錄上已出場、今天又講「鴻海23X是買點」 | 會員持股列一律改成回顧，不公開 | 有本股的當下條件就照條件歸類（引句講的是「X集團的」另一檔時不算） |
| 「賣掉的嘉澤，什麼時候買回來？我會跟你們講，不用緊張」 | 回顧或沒有看法，不公開 | 暫不買回，列觀望不碰（紀錄上仍持有也一樣，對應 10/15 管理者「持股＋不碰」） |

仍交給問卷、沒有改的：「X已經不是賣點」「X不要殺低」這類反對賣出的說法（10/16 聯電）。講者沒有持有時可能是教學例子，也可能是買點提示，目前列或不列都算通過。

## 10/15 現行邊界（優先於下方早期設計紀錄）

| 要判斷的事 | 可採證據 | 不可推論 |
|---|---|---|
| 當日成交 | 本人／會員已完成的當日交易；逐字稿成交候選須併入既有 AI 裁決批次，附本股原句並通過程式核對 | 「今天賣就是阿呆」、歷史高點賣出、打算買、可以買都不等於已成交 |
| 當日操作通知 | 核對完整通知原文後的明確執行指令；沿用既有操作紀錄定義 | 不能優先信任錯誤解析；「如果想買者可以買」只算進場建議 |
| 部位 | 已核對未全數出場紀錄、明講本人／會員仍有部位 | 觀眾提問自己的持股，不等於講者持有；歷史賣出不等於今天出場 |
| 觀望注意 | 本股有向前的偏多判斷、明確可買建議或可辨認的買點條件；未必已持有 | 只報價、點名、歷史例子或借別檔訊號，不足以公開 |
| 觀望不碰 | 本股現在禁買、尚未出現買回條件、明確不參與或本股風險 | 不把「不准殺低」當作禁止買進，也不能拿未來條件解除當下禁買 |

部位與新進場立場是兩個維度：部分減碼後仍持有，同時可以暫不買回。嘉澤的「剩餘持股＋觀望不碰」不是互相取消；只有已確認全數出場才關閉整個回合。同一進場語境不能同時注意與不碰。

管理者同意在內容驗收中將會員持股／觀望注意視為同組可接受結果；此容許不會讓觀望建立虛構交易、成本或持有回合，也不放寬買賣的證據門檻。

引句只取本股可引用區，前文只供理解；換成未點名的新例子即停止。不能把不同區段接起來偽造一句。沒有有效引句支持原分類的爭議觀望候選，只隔離本股；原稿同句已有可核對的向前條件時保留注意，不因模型無有效答案而漏收。模型配額、原文失效、整體資料損壞仍須留明確錯誤，不冒充發布成功。

## 為什麼要做

同一份 10/08 逐字稿跑了 33 輪，只有 13 輪通過人工答案。原因不是十幾個獨立的錯：規則處理後每一檔大約有 96% 的機率落在對的分類，但一天有二十檔、要全部對，機率只剩一半；每補一條規則只推高其中一檔，重跑時其他十九檔又各擲一次骰子。

初判（第一次擷取）一致率最低的都是靠語氣判斷的分類：宏達電 52%、創意 65%、聯發科 69%、環球晶 71%；有事實可核對的（群聯的條件、國巨的「絕對不買」、勤誠的成本）接近 100%。

## 三層分流

| 層 | 條件（程式判定） | 怎麼處理 |
|---|---|---|
| 直接歸類 | 當日會員通知已有這一檔的買賣；或原文有「今天＋買／賣＋本股名稱」的明確句；或原文明講目前持有（我目前只有 X、手中的股票有 X 而且講了成本、X…繼續抱著） | 不問模型，照證據歸類 |
| 一致通過 | 目前是會員持股，初判、覆核、規則處理後三次都在這一類，而且股名附近沒有疑點（見下） | 不問模型 |
| 送裁決 | 其餘：所有觀望注意、觀望不碰、回顧、排除的台股；以及有疑點或三個階段不一致的持股與買賣 | 問卷，最多三輪，一輪一個請求 |

疑點（只看股名所在那一句與其後一小段）：提到過去的日子而目前列買賣或持股；有「不買、不要追」的講法而目前不是觀望不碰；有「抱著、還在、沒有賣」的講法而目前不是持股；有買賣的講法而目前是觀望或不公開；有人提問；拿來對照或舉例；假設語氣而目前列買賣。

## 問卷：模型只回答事實，分類由程式決定

每一檔只給它自己的段落。段落分兩部分：`text` 是股名所在那一句到其後約 220 字（股名用【】標出），答案與引句只能出自這裡；`before` 是前文，只供理解。段落在別家公司名稱前切開時，尾巴剩下的半句會拿掉。

| 題目 | 定義 | 不算 |
|---|---|---|
| buy_today / sell_today | 講者本人或會員在節目當天已經買進（賣出），或當天明確通知會員 | 昨天或更早；打算、等條件、假設；對個別提問說「建議先賣」；別人的買賣；沒報名字的「今天賣出一檔」 |
| holding_now | 明講他或會員現在還持有：還在、沒有賣、繼續抱、我有、我們本來就有了、我只有、我的成本多少、昨天買而今天仍在講自己的部位 | 只是看好；已賣掉；「我沒有買」；對觀眾的假設句；講的是整個族群 |
| past_trade | 提到不是當天的買賣 | — |
| about_itself | 有講這一檔自己的事：行情、線型、業績、籌碼，或對它的指示與意願。拿它當大跌、跌停、追高受傷的例子也算（只有一句也算） | 只被念到名字；襯托別檔；批評別人時順帶提到；只說「我沒有買它」；那個字在句子裡是一般用語 |
| now | 對「現在要不要進場」的表態：buy_ok、conditional（給了條件而且沒說現在不能買）、not_yet（現在還不能、太急、離均線太遠）、prohibit（不買、不要追、不推薦、不再介紹）、none | 「不會買」就算是比照別檔時說的也是 prohibit |
| tone | now 是 none 時才用：bullish、bearish（含負面示範）、neutral（只描述或只回顧）。反話與賣壓竭盡是 bullish | — |

答 true 的題目與立場都要附從 `text` 照抄的引句。程式核對：引句必須逐字出現在可引用的範圍；買賣的引句裡要有本股名稱或代號、不能只說「昨天」；持有的引句不能是假設句。核對不過，那一題不算數。

## 決定順序（程式，固定）

1. 當天買進 → 買入；當天賣出 → 賣出（兩者並存不由裁決決定）
2. 明講目前持有 → 會員持股
3. 沒有講這一檔自己的事 → 有過去買賣列回顧，否則排除（都不公開）
4. 只回顧過去的買賣、沒有現在的看法 → 回顧
5. now 是 prohibit、not_yet → 觀望不碰；buy_ok、conditional → 觀望注意
6. now 是 none：bullish → 觀望注意；bearish → 觀望不碰；neutral（只描述行情、沒有結論）→ 不列（`VERDICT_NEUTRAL_CLASS`）

## 定案規則

- 第一份可用的答案就和流程的分類一樣：定案，不再問。
- 觀望注意與觀望不碰互換：三票裡兩票相同就改。
- 跨過公開／不公開的改動，以及改進或改出買入、賣出、會員持股：三票都要一樣。
- 問卷認為當天有買賣、流程卻沒有：不新增，標未定。買賣只認程式核對得到的明確句或會員通知。
- 其餘標「未定」：維持流程的分類，不擋其他檔，記進「分類裁決」表等人工。
- 裁決後的分類是最後答案：後面的規則仍可改文字，把這一檔搬走時收尾會搬回來並記一筆。
- 任何錯誤都不擋流程：印一行、記一筆，分類維持原樣。

## 怎麼讓同一份原稿每次答案一樣

- 定案的裁決連同段落指紋與版號寫進試算表的「分類裁決」工作表；同一段原文、同一版基準之後直接沿用，不再問模型。
- 表上的「人工裁決」欄填了分類名稱（買入、賣出、會員持股、觀望注意、觀望不碰、回顧、排除），那一天那一檔一律照它。
- `CLASS_ADJUDICATION`：`off` 不做；`shadow` 只記錄不改分類；`on` 照裁決改列（預設）。

## 2026/10/14：主體、部分部位與共同拒買

- 部分賣出不等於全數出場：當日減碼列保留，但未出場回合與剩餘續抱狀態維持；沒有已存在部位時，不因「部分」二字憑空新增持有。較後的全出記錄仍關閉回合。
- 對觀眾自己的持股提供續抱建議，不等於講者或網站會員的持股紀錄；分類可列觀望注意，說明保留量能與出場條件。
- 原文明確把同一短名單的標的共同拒買，依該段直接核對，裁決舊票不能把其中一檔排除。條件、過去式、雙重否定、轉場、單數及其他人主詞不套用。
- 觀望注意仍接受有依據的買點、等待條件及向前看的本股訊號；只描述行情不自動納入。說明必須與分類、主體、日期及本股資料一致，材料少不借其他股票湊字。
- 原稿與分類相同的人工核對書面說明沿用；指紋、來源或分類改變時重新複核。

## 額度

Gemini 文字模型的額度是每分鐘 15 次、每天 500 次。裁決一輪一個請求（依字數裝箱，上限約 48,000 字），最多三輪；檢驗模式把所有日期併進同一個請求，預設三輪。

### 部位範圍與公開說明分離（10/14）

通知的部分／全部賣出，依原始解析明細的來源 ID、代號、日期核對。改写公開說明不改變部位狀態；例如『並非整檔全數出場』不能因包含全數出場字樣而關閉回合。同來源中有全數出場時仍以全數為準。張數未知時保留部分賣出事件，不推算部分已實現報酬。

### 否認部位、錯位資料與否定方向（2026/10/16）

- 同一段先說「我的股票」、隨後點名否認持有時，以本股完整語句判斷。否認持有只排除部位；若另有本股有效的前瞻買點，可評估觀望注意，不能因此虛構買賣。
- 本輪原文明講沒有持有，舊持股列不得藉「沿用前一版」重新建立部位。原稿、歷史操作與人工修正分開核對。
- 「已不是賣點」不等於「已不是買點」。補充說明提示詞與本股技術詞檢查均核對否定所指的買／賣，錯誤句移除；若來源同時有不同時點的兩種說法，不單憑關鍵字自動改列。
- 資料中的數字／字串型別不能證明誰寫入。已確認的名稱與說明主詞錯位，用另存私人備份、原稿與原說明指紋、唯一身分核對及原子批次修復，不以重跑AI掩蓋錯位資料。
- 答案檔的`forbidden_stock_categories`只阻擋特定股票的錯誤類別，不強迫收錄；正式`apply-rules`仍由規則判定，答案只檢查。
