# 分類裁決：判斷基準與定義

2026/10/08 建立。程式在 `pipeline/pipeline.py` 的「分類裁決」區塊（`adjudicate_classes`、`verdict_class`、`verdict_settle`）；題目是 `ADJUDICATE_SYSTEM`。題目或決定順序一改，就換 `VERDICT_VERSION`，舊裁決不再沿用。

## 為什麼要做

同一份 10/08 逐字稿跑了 33 輪，只有 13 輪通過人工答案。原因不是十幾個獨立的錯：規則處理後每一檔大約有 96% 的機率落在對的分類，但一天有二十檔、要全部對，機率只剩一半；每補一條規則只推高其中一檔，重跑時其他十九檔又各擲一次骰子。

初判（第一次擷取）一致率最低的都是靠語氣判斷的分類：宏達電 52%、創意 65%、聯發科 69%、環球晶 71%；有事實可核對的（群聯的條件、國巨的「絕對不買」、勤誠的成本）接近 100%。

## 三層分流

| 層 | 條件（程式判定） | 怎麼處理 |
|---|---|---|
| 直接歸類 | 當日會員通知已有這一檔的買賣；或原文有「今天＋買／賣＋本股名稱」的明確句；或原文明講目前持有（我目前只有 X、手中的股票有 X 而且講了成本、X…繼續抱著） | 不問模型，照證據歸類 |
| 一致通過 | 目前是會員持股，初判、覆核、規則處理後三次都在這一類，而且股名附近沒有疑點（見下） | 不問模型 |
| 送裁決 | 其餘：所有觀望注意、觀望不碰、回顧、排除的台股；以及有疑點或三個階段不一致的持股與買賣 | 問卷，最多三輪，一輪一個請求 |

疑點（只看股名所在那一句與其後一小段）：提到過去的日子而目前列買賣或持股；有「不買、不要追」的講法而目前不是觀望不碰；有「抱著、還在、沒有賣」的講法而目前不是持股；有買賣的講法而目前是觀望或不公開；有人提問；拿來對照或舉例；假設語氣而目前列買賣。

## 問卷：模型只回答事實，分類由程式決定

每一檔只給它自己的段落。段落分兩部分：`text` 是股名所在那一句到其後約 220 字（股名用【】標出），答案與引句只能出自這裡；`before` 是前文，只供理解。段落在別家公司名稱前切開時，尾巴剩下的半句會拿掉。

| 題目 | 定義 | 不算 |
|---|---|---|
| buy_today / sell_today | 講者本人或會員在節目當天已經買進（賣出），或當天明確通知會員 | 昨天或更早；打算、等條件、假設；對個別提問說「建議先賣」；別人的買賣；沒報名字的「今天賣出一檔」 |
| holding_now | 明講他或會員現在還持有：還在、沒有賣、繼續抱、我有、我們本來就有了、我只有、我的成本多少、昨天買而今天仍在講自己的部位 | 只是看好；已賣掉；「我沒有買」；對觀眾的假設句；講的是整個族群 |
| past_trade | 提到不是當天的買賣 | — |
| about_itself | 有講這一檔自己的事：行情、線型、業績、籌碼，或對它的指示與意願。拿它當大跌、跌停、追高受傷的例子也算（只有一句也算） | 只被念到名字；襯托別檔；批評別人時順帶提到；只說「我沒有買它」；那個字在句子裡是一般用語 |
| now | 對「現在要不要進場」的表態：buy_ok、conditional（給了條件而且沒說現在不能買）、not_yet（現在還不能、太急、離均線太遠）、prohibit（不買、不要追、不推薦、不再介紹）、none | 「不會買」就算是比照別檔時說的也是 prohibit |
| tone | now 是 none 時才用：bullish、bearish（含負面示範）、neutral（只描述或只回顧）。反話與賣壓竭盡是 bullish | — |

答 true 的題目與立場都要附從 `text` 照抄的引句。程式核對：引句必須逐字出現在可引用的範圍；買賣的引句裡要有本股名稱或代號、不能只說「昨天」；持有的引句不能是假設句。核對不過，那一題不算數。

## 決定順序（程式，固定）

1. 當天買進 → 買入；當天賣出 → 賣出（兩者並存不由裁決決定）
2. 明講目前持有 → 會員持股
3. 沒有講這一檔自己的事 → 有過去買賣列回顧，否則排除（都不公開）
4. 只回顧過去的買賣、沒有現在的看法 → 回顧
5. now 是 prohibit、not_yet → 觀望不碰；buy_ok、conditional → 觀望注意
6. now 是 none：bullish → 觀望注意；bearish → 觀望不碰；neutral（只描述行情、沒有結論）→ 不列（`VERDICT_NEUTRAL_CLASS`）

## 定案規則

- 第一份可用的答案就和流程的分類一樣：定案，不再問。
- 觀望注意與觀望不碰互換：三票裡兩票相同就改。
- 跨過公開／不公開的改動，以及改進或改出買入、賣出、會員持股：三票都要一樣。
- 問卷認為當天有買賣、流程卻沒有：不新增，標未定。買賣只認程式核對得到的明確句或會員通知。
- 其餘標「未定」：維持流程的分類，不擋其他檔，記進「分類裁決」表等人工。
- 裁決後的分類是最後答案：後面的規則仍可改文字，把這一檔搬走時收尾會搬回來並記一筆。
- 任何錯誤都不擋流程：印一行、記一筆，分類維持原樣。

## 怎麼讓同一份原稿每次答案一樣

- 定案的裁決連同段落指紋與版號寫進試算表的「分類裁決」工作表；同一段原文、同一版基準之後直接沿用，不再問模型。
- 表上的「人工裁決」欄填了分類名稱（買入、賣出、會員持股、觀望注意、觀望不碰、回顧、排除），那一天那一檔一律照它。
- `CLASS_ADJUDICATION`：`off` 不做；`shadow` 只記錄不改分類；`on` 照裁決改列（預設）。

## 實測（唯讀檢驗）

「單日品質核對與更新」選 `verdicts` 模式，日期可用逗號分隔。拿有人工答案的日子把每一檔都送問卷，不寫任何資料。

10/05–10/08 四天 75 檔、各問 5 輪（段落尾巴裁切與一輪一個請求上線之前的版本）：

- 問卷多數票與人工答案相符 68 檔（91%）；五輪完全相同 35 檔（47%）；375 份答案有 59 份因為沒附引句不能用。
- 流程本來判對時：65 檔維持、8 檔標未定（仍是對的）、2 檔被改錯。
- 流程判錯時（漏掉、多列、方向相反，共 109 種情況）：救回 78、標未定交人工 27、仍錯而且定案 4。

被改錯的兩檔：金山電（段落收在「只要不買」，後面接的是國巨——已改成裁掉半句）；聯發科（「我沒有買聯發科，所以我不被跌到」，問卷當成負面例子，人工答案是不列）。

開啟改列後的 10/08 單日預覽（唯讀、真實模型）跑了兩次，人工答案都全數通過，各用 15、16 個請求：

- 第一次：模型把金山電判成會員持股，裁決三票一致改回觀望注意（沒有裁決這一輪會被人工答案擋下）。
- 第二次：模型把鈺邦判成觀望注意，裁決改回會員持股；創見三票一致不列；創意只描述「回來碰季線」不列；南亞科不列，而且不再被「沿用前一版」帶回來。金山電這一次沒有三票一致，維持原分類，由既有的持股主詞核對改列觀望注意。

## 管理者裁示（2026/10/08）

1. 只描述行情、沒有買賣結論的台股（「創意回來碰季線」）：不列，除非另有資訊。主提示詞、立場欄位的對應（`category_from_stance`）與裁決三處同一條規則；原本是買入或持股、只因日期降到觀望的列不在此限。
2. 「我沒有買 X，所以我不被跌到」：不列。原文另外講了這一檔自己的負面行情或風險（跌停、連跌、追高套牢、以後也不買）才列觀望不碰。
3. 給了等待條件但沒有明講現在不能買（「等群聯回測季線再上去」）：觀望注意。

## 2026/10/09：正式逐字稿覆核與 v4 段落邊界

10/08 單日正式套用的第一輪被公開文字關卡阻止，沒有寫入。該輪創意又被列為觀望注意；正式站逐字稿第 11 段只有「創意回來碰季線」作為線型例子，後句「記憶體後面有一波」「這一個發動」已換到族群話題，不能當成創意的買進條件。問卷輸入現在遇到「所以／另外／至於／接著／再來」引入沒有再點名本股的新話題時，只保留本股那一句；同一檔之後再點名則另建段落。可引用段落改動，因此裁決版號從 v3 換為 v4，舊指紋的裁決不沿用。

10/08 人工答案也從兩種容許分類收緊為鈺邦＝會員持股、群聯＝觀望注意；創意、創見、南亞科列為不應公開。個股文字另外擋「觀望卻寫續抱」與公開說明中的來源／編輯過程；來源資訊不足時只寫已核對的事實，不湊字數或借別檔技術條件。

## 額度

Gemini 文字模型的額度是每分鐘 15 次、每天 500 次。裁決一輪一個請求（依字數裝箱，上限約 48,000 字），最多三輪；檢驗模式把所有日期併進同一個請求，預設三輪。
